# Glossary

Each term has one meaning in every document of this project. Requirements, entity model, use cases and code use these words. The Avoid column lists words that must not be used for the concept.

| Term | Definition | Avoid |
|---|---|---|
| Hero | A player-controlled figure: one of the eight campaign heroes, while it fights in a battle or waits in the reserve. | |
| Party | The four active heroes who fight in a battle. | Squad |
| Reserve | The four heroes who are not in the party; they join the party only in town. | Bench |
| Roster | All eight campaign heroes: the party and the reserve together. | |
| Hireling | A man-at-arms hired in town for 60 gp. He costs 10 gp per delve and takes no checkpoint picks. | |
| Downed | A hero or enemy at 0 HP and conscious: it cannot act, and a further hit kills a hero outright. | Unconscious |
| Knocked Out | An enemy at 0 HP. It cannot act until it is finished by a coup de grace. | Dead |
| Coup de Grace | A single adjacent action that kills a knocked-out enemy and ends the activation. | Finishing blow |
| Camp | A night spent on a cleared floor: half of each hero's lost HP is recovered on a 2-6, and the party is interrupted on a 1. | Rest |
| Trapped Gear | Armor with a bane while worn (Poison Oak Armor poisons its wearer each turn). It comes off freely in town. | |
| Cursed Artifact | Armor with a boon and a bane (Hollow Mail: +2 temporary HP each battle, -1 to every d20). It cannot be removed until a town wizard lifts the curse for 300 gp. | Cursed item |
| Weary | A hero who was interrupted while camping: -1 on every d20 until a night that is not interrupted. | |
| Heroism | A hero's pool of points, equal to its caster level, refilled each battle. Spending one adds +1 to every d20 that hero rolls until the next player phase. | |
| Enemy | A hostile creature the game controls. | |
| Enemy Band | A group of enemies that share one morale check. | |
| Battle | One fight on one map, from its first round to victory or defeat. | |
| Skirmish | Standalone play: one battle on a classic or altar map, started from the skirmish screen. | Quick game |
| Dungeon Run | A standalone run through a random dungeon of three floors, won by taking the way out of floor three. | Random map |
| Delve | One campaign expedition: three floors, entered from town and left back to town. | |
| Floor | One level of a dungeon run or a delve. Each has three floors. | Storey |
| Stairs | The way between floors: stairs down on floors one and two, the way out on floor three. | Portal |
| Map | The battlefield of a battle: a classic map, the altar map, or a generated dungeon floor. | |
| Campaign | The persistent game: roster, gold, stash, day count and checkpoints, carried across delves. | |
| Town | Oakmoor, the campaign screen where heroes rest, shop, learn and change roster between delves. | |
| Gold | The campaign's currency, earned from defeated enemies and chests and spent in town. | Coins, Money |
| Serious Injury | The D66 roll a hero makes at the end of a battle if it was out of action (0 HP). 11-35 is dead; 36-66 recovers. | |
| Stash | The campaign's shared store of items and gear; heroes take what they need from it in town. | Warehouse |
| Pack | The items one hero carries, such as potions, oil, holy water and ammunition. | Bag |
| Gear | A weapon, armor or shield that a hero equips. | Kit |
| Item | A consumable or ammunition: healing potion, oil flask, holy water, spell scroll, arrow, crossbow bolt. | |
| Spell | An ability of a mage, ranger or cleric, paid for in HP. | Incantation |
| Spell Debt | HP a caster has paid for spells. It cannot be healed during the battle and is cleared by resting in town. | Mana, Spell points |
| Checkpoint | An XP total at which each hero receives advancement picks: 30, 100, 280 and 780 XP. | Level-up, Milestone |
| Advancement Pick | One choice a hero owes at a checkpoint, taken from the options offered. | Perk, Upgrade |
| Feat | A named ability a hero takes as an advancement pick. | Talent |
| Teacher | A town trainer who must be present to teach a spell: the skills trainer, the arcane tutor or the divine tutor. | Instructor |
| Spell Scroll | A dungeon item that teaches one unknown spell in town when its class teacher is present. | Tome |
| Round | One player phase, in which each ready hero gets one activation, followed by one enemy phase. | |
| Activation | One hero's move and action within a player phase, in any order. | |
| Search Phase | The period after a floor's enemies are defeated. The floor stays open, and heroes search, open chests and rest. | |
| Search Round | One round of the search phase. Enemies do not act during it. | Search turn |
| Wanderer | An enemy that arrives during the search phase, out of every hero's line of sight. | Reinforcement |
| Wounded | A living party hero at half its maximum HP or less. It rolls at -2 on every d20 until healed above half. | |
| Morale | The check an enemy band makes once a member is hurt or half the band is down. A band that fails breaks and flees. | Courage |
| Reach | The hexes an enemy can strike in melee. | |
| Reaction | A free melee attack an enemy makes when a hero enters or leaves its reach during a move. | Opportunity attack, Attack of opportunity |
| Elevation | A tile's level relative to its neighbors: -1 for a pit or channel, 0 for ground, +1 for a table or barrel, +2 for a raised ledge. | Z-level |
| Facing | The side a hero or enemy faces, set by the direction it last moved. A melee attack from behind gets +2. | Orientation |
| Altar | A map objective. A hero claims it by standing on it and holding it through an enemy phase. | |
| Shrine | A map feature that restores up to 4 HP to a hero standing on it, while it has a charge. | |
| Chest | A map container that a hero opens for gold and items. | Strongbox, Coffer |
| Trap | A hidden or visible hazard on a map that springs only when a party member enters its tile. | Snare |
