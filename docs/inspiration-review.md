# Inspiration review: what else the sources offer

Second pass over the sources in `inspirations.md`, in that order. Each source was re-read for mechanics the game does not yet use. Source notes: `C:\Users\user\Documents\wiki\rpg\`. Fit is judged against the game as built: four heroes, hex tactics, a three-floor delve, a town between delves.

Verdicts: **Adopt** (fits, add to the feat or rule list), **Consider** (fits, needs a decision), **Skip** (already in the game, or out of scope under `features.md`).

## Ranked for the framework

1. **Feat menu (adopt):** Heroism, Fate Points, and Aptitudes are the same resource in three shapes. Pick one name and one rule. Feeds item 4 in the todo list.
2. **Serious injury (adopt):** Mordheim's D66 table replaces permanent death, which `features.md` deferred. It is the only fix for heroes that die for good.
3. **Surprise (adopt):** one 1d6 rule for both sides, used on wanderer arrival (FR-025).
4. **DC ladder (adopt, spec-only):** no code change; sets one scale for the checks.
5. **Hirelings (adopt):** HeroQuest henchmen, Mordheim hired swords, and Moldvay retainers are one rule: hired reserve with upkeep and morale.
6. **Shaken / Wounded (consider):** a tempo state between down and healthy. Two sources agree, so it is more than one designer's idea.
